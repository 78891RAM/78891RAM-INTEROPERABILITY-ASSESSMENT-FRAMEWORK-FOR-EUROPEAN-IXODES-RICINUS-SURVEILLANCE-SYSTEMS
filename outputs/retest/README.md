# Retest / internal-consistency check — evidence and results

Generated by `tick/scripts/build_retest_worksheet.py` and
`tick/scripts/evaluate_retest.py` while auditing the dissertation's
"49 of 50 criterion decisions" internal-consistency claim (Section 3.3/4.3),
which had no computation or saved record behind it anywhere in the repo
before this.

## Files

- **`blind_worksheet_sys01_02_04_05_11.csv`** — evidence-only worksheet for
  5 systems (random.seed(42)), scores and audit notes stripped. Built for a
  genuine blind re-scoring exercise.
- **`answer_key_sys01_02_04_05_11.csv`** — the real scores for those same 5
  systems, kept separate from the worksheet above. Once opened, that
  worksheet can no longer be used blind — see the git history / chat log
  for why (the user asked to see the real scores directly).

- **`independent_scoring_5system.csv`** / **`independent_evaluation_5system.csv`** —
  Claude's independent re-scoring of SYS03, SYS09, SYS10, SYS12, SYS13
  (chosen because their original scores had not been discussed elsewhere in
  the conversation), and the resulting comparison against `data/systems.csv`.
  Result: 35/50 (70%) agreement.
- **`independent_scoring_8system.csv`** / **`independent_evaluation_8system.csv`** —
  extended to SYS07, SYS08, SYS14. Result: 59/80 (73.8%).
- **`independent_scoring_remaining6.csv`** — Claude's independent re-scoring
  of the last 6 systems (SYS01, SYS02, SYS04, SYS05, SYS06, SYS11). Not a
  blind exercise for these 6 specifically — their real scores had already
  come up earlier in the conversation, so this only tests whether the same
  rubric, applied mechanically from evidence, reproduces the known answer.
- **`independent_scoring_full14.csv`** / **`independent_evaluation_full14.csv`** —
  all 14 systems combined. Result: **109/140 (77.9%)** agreement across
  every system in the framework. Full per-criterion reasoning (rubric
  definition, evidence quoted, score assigned) is written up in the
  published artifact:
  https://claude.ai/code/artifact/e7d48e56-7edc-47a6-800d-7b9967c09268

## What this is, and isn't

This is **Claude's independent re-scoring**, not a human test-retest — the
dissertation's own text (Section 4.3) correctly frames its "49/50" claim as
a *non-blind, non-independent, internal consistency check* carried out by
the same assessor within the same study. Neither figure should stand in for
the other; they are different checks answering different questions. Citing
`109/140` as if it were the dissertation's described exercise would
misrepresent it, exactly as citing an unbacked "49/50" would.

If a genuine human re-scoring pass is done later (by the dissertation's
author or a second rater), run it through
`tick/scripts/evaluate_retest.py` and save the result alongside these files
using the same naming pattern.

See also: `tick/outputs/weighting_robustness.csv` (a related but separate
robustness check — the effect of alternative criterion weightings on
readiness/integration classification, not on re-scoring agreement).
